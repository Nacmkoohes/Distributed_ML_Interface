# Distributed ML Inference Platform

A distributed machine learning inference platform designed to study
the scalability, performance, and fault tolerance of ML inference services.

## Project Status

🚧 In development

## Research Question

How do different load-balancing strategies affect the scalability,
latency, throughput, and resource utilization of a distributed
machine learning inference system?

## Planned Features

- ML inference API
- Multiple inference workers
- Load balancing
- Health checks
- Fault tolerance
- Performance benchmarking
- Prometheus monitoring
- Grafana dashboards

## Tech Stack

- Python
- FastAPI
- Scikit-learn
- Docker
- PostgreSQL
- Prometheus
- Grafana
- Locust
- Pytest

## Architecture

The initial architecture will consist of a FastAPI service
that communicates with one or more ML inference workers.

More detailed architecture documentation will be added as
the project develops.
